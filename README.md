# Right-gradient VPIC dashboard

This directory is a static, self-contained website for GitHub Pages. It contains dashboard HTML, local CSS/JavaScript, rendered PDF previews, source PDFs, five extended H.264 movies, and the final comparison figure/data. The 3di movie uses the designated second-restart outputs.

The timestamp manifest is included in sanitized form: absolute source paths were removed; run, frame, time, normalization, and plotting metadata remain. Simulation datasets and analysis scripts are not included.

For a local preview, open `index.html` in a browser or run `python -m http.server 8000` from this directory and visit `http://localhost:8000`.
